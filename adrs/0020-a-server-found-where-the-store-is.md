# 0020 A server for several callers, found where the store is found

2026-09-28. Several callers reach one store through a gRPC server, `kb serve <root> --listen <host:port>`, hosting the same servicer; it takes changes one at a time and owns the store it serves, so an in-process client may read that store but not change it. A caller finds the server where it would find the store: the search upward from the working directory, or `KB_ROOT`, stops at a directory holding `kb/store.yaml` (the store, reached in-process) or `kb/server.yaml` (the connection, holding the server's `address`, reached over the network), never both. The server is not bound to localhost: it listens on the address it is given, any interface included, so it works across Docker networking between containers; there is no authentication in this version, and the network it listens on is its boundary. The clock stays the in-process client's; a server stamps with its own. The user's decisions (2026-09-28): the connection config sits where the search looks for the store; the server is not localhost-only. Chosen over locking the store for several in-process callers. Extends 0008 and 0018.
